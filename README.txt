วิธีใช้งาน
เปิด index.html ใน Chrome, Edge หรือ Firefox ได้ทันที ไม่ต้องติดตั้งแพ็กเกจ

ไฟล์ประกอบ
index.html — โครงสร้าง HTML
styles.css — การจัดหน้า สี การ์ด responsive และเอฟเฟกต์
script.js — การเลื่อนอัตโนมัติ ปุ่มควบคุม และหน้าต่างสูตรอาหาร
assets/ — ภาพการ์ด 3 แบบที่ตัดจากภาพอ้างอิง

เลื่อนแนวนอนด้วย touchpad/นิ้ว หรือกดปุ่มลูกศร ใช้ปุ่มพักเพื่อหยุดเลื่อนอัตโนมัติ
คลิกการ์ดเพื่อดูรายละเอียด กด Escape เพื่อปิดหน้าต่าง
รายละเอียดสูตรใน script.js เป็นตัวอย่าง สามารถแทนด้วยสูตรจริงได้
ภาพจากต้นฉบับมีขนาดเล็ก หากต้องการใช้งานจริงควรแทนด้วยภาพความละเอียดสูง
